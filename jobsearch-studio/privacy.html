Privacy policy

JobSearch Studio · last updated November 8, 2026

JobSearch Studio is a personal job-search tool. Its only user is its owner, Susil Kessav, and it runs entirely on the owner's own computer.

What it accesses

With the owner's permission, it connects to the owner's own Gmail account using Google's read-only Gmail permission (gmail.readonly). It reads only messages related to job applications:

  • confirmation emails sent by employers or job sites after an application is submitted;
  • verification codes and links sent by job sites when an account is created or signed in to.

It never sends, deletes, changes or marks any email as read.

How the data is used and stored

  • Information from these emails (for example, that an application was received on a given date, or a one-time verification code) is used only to record the owner's own application status and to complete the owner's own sign-ups.
  • It is stored only on the owner's computer. The Google sign-in token is kept in the computer's macOS Keychain.
  • No Gmail data is sent to any server, shared with or sold to anyone, used for advertising, or used to train AI models.

Google API Services User Data Policy

JobSearch Studio's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the token from Keychain and the tool's local data folder removes everything it stored.
