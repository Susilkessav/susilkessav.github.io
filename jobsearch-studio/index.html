JobSearch Studio

JobSearch Studio is a personal tool that Susil Kessav runs on a personal computer to organize a job search: it collects job postings, tracks applications and helps fill in application forms.

It connects to one Gmail account, its owner's own, with read-only access. It uses that access only to find job-application emails: confirmation messages after an application is submitted, and the verification codes or links that job sites send when an account is created. It never sends, deletes, changes or marks any email as read.

It is not offered to anyone else, and it has no other users.
